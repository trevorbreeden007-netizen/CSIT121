Lessons Learned

Working on this portfolio project helped me realize how much I learned throughout the semester. At the start of the class, writing HTML was confusing and I wasn’t sure how websites were put together. As I completed more labs, I became more comfortable using headings, paragraphs, links, and organizing my files correctly. One of things that made me the most happy was was being able to combine all my labs into one website that looks super organized and professional like you would see on the internet.

Testing the websites i make on different browsers and on a mobile device showed me why responsive design is important and why you need to test everything. Some things looked fine on my computer but didn’t work as well on a smaller screen like with the header i originally picked. This helped me to better understand why media queries and flexible layouts matter. It also taught me that testing a website is necessary to make sure it works well for everyone.

All in all my last few months taking this class taught me the basics of web development and how websites are built from the ground up which is something i had little expereince in before. I learned how HTML and CSS work together to create a clean layout and better user experience to make a website more beautiful. I also feel more confident in my ability to create and fix webpages on my own. These skills will be helpful as I continue learning more about technology and web design.
