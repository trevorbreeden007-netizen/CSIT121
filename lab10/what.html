Definition

DCAT is a standard way to describe datasets so people can easily find and share them online with each other. It basically gives everything a clear label so different websites and computers can understand the data the same way.

The version 3 of DCAT builds on the earlier versions of DCAT by adding clearer ways to describe APIs and dataset relationships. This is important because many modern datasets are accessed through online services instead of only downloadable files.

DCAT uses RDF which means it is machine readable and works well with linked data technologies. DCAT helps keep data organized and usable across many platforms on the internet.
